Open the [HTML guide](index.html) for the schema-domain overview and a short
checkout walkthrough. [Working with the integrated stage](stage/index.html)
explains the delivered forms, layers, traversal, views and recorded proofs.
Use the [suite map](suite.md) to browse all 23 released repositories by tier,
or the [stage reference](../stage/README.md) for native setup and reproduction.

The site retains the imported layout, CSS and PNG. Two prose terminology
substitutions in the schema guide use “type” and “group”; technical CSS and font
API identifiers retain their required syntax. [site.json](site.json) preserves
the four original asset hashes and records the current hashes and sizes of those
assets and the integrated-stage page. Navigation and the hub now link the guide.
External links and font services are not fetched by the documentation checker.
