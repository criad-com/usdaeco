# usdAECO suite documentation

Read the [Built Environment schema guide](schemas/usdAeco/overview.md) for the core
schemas and [Working with the integrated stage](stage/index.md) for the delivered
forms, layers, traversal, views and recorded proofs. Both guides have styled HTML
versions linked at the top. The [HTML hub](index.html) includes a short
checkout walkthrough. Use the [suite map](suite.md) to browse all 22 released
repositories by tier, or the [stage reference](../stage/README.md) for native setup
and reproduction. [Verification notes](verification.md) explain the scope of the
source gate.

The site retains the imported layout, CSS and PNG. Two prose terminology
substitutions in the schema guide use “type” and “group”; technical CSS and font
API identifiers retain their required syntax. [site.json](site.json) preserves
the four original asset hashes and records the current hashes and sizes of those
assets, both guide formats and the standalone SVG figures. Markdown figures use
explicit colours and transparent backgrounds for light and dark GitHub themes.
Navigation and the HTML hub retain their styled-guide links.
External links and font services are not fetched by the documentation checker.
